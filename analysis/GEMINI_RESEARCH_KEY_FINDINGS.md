## Puzzle Architecture (Lone Shark Games)
- Designed by Mike Selinker / Lone Shark Games
- Nonlinear, multi-step ARG structure
- Requires "creativity, logic, and straight-up obsession"
- Designed to reward community collaboration
- **"LIF(E)CHANGE" Grid:** 9x9 Sudoku substituting numbers with LIFECHANG(E) letters
- **Nine-Video Playlist:** Each video's pinned comment links to a variety puzzle → contributes to final code
- **Zodiac-style ciphers:** Some visual clues use glyphs requiring alphanumeric/book cipher decoding
